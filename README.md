# Bikeshare Project

This project analyzes bikeshare data for three US cities using Python.

## Description

The program allows the user to select a city, month, and day, then displays statistics about:
- most common travel times
- most popular stations
- trip duration
- user information

## Files Included

- bikeshare.py - main Python script for the bikeshare analysis
- README.md - project documentation
- .gitignore - ignores CSV data files

## How to Run

Make sure Python is installed, then run this command in the terminal:

python bikeshare.py

Follow the prompts in the terminal to choose filters and view statistics.

## Data Files

The project uses bikeshare CSV data files for:
- Chicago
- New York City
- Washington

These CSV files are ignored by Git using .gitignore and are not tracked in the repository.
